# Mini juego: La gallina cruzando la calle

Proyecto de práctica para un videojuego 2D simple en Python con Pygame.

## Requisitos
- Python 3.13
- Entorno virtual `.venv`

## Instalación
1. Crear el entorno virtual:
   `py -3.13 -m venv .venv`
2. Activar el entorno:
   `.venv\Scripts\Activate.ps1`
3. Instalar dependencias:
   `python -m pip install -r requirements.txt`
4. Generar assets placeholder:
   `python generar_assets.py`
5. Ejecutar el juego:
   `python main.py`

## Contenido
- `main.py`: juego principal con niveles, vidas, puntaje y pantallas.
- `generar_assets.py`: genera sprites y sonidos placeholder para sustituir más adelante.
- `assets/`: recursos gráficos y sonoros del proyecto.
